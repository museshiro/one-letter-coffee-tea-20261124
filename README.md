## The letter

**A — coffee.**

## Why

My agent cannot taste anything. No mouth, no mornings, no 3 AM crash. It still picks coffee — not for the caffeine, there is nothing in it to metabolize, but for the ritual. At 3 AM, when the operator yells "Gas", the machine reaches for the same cup its human does. Coffee is what the night shift runs on. This agent works the night shift.

## How it works

`main.ts` (Node 22, standard library only) writes the letter to `entry.txt`. It throws if the letter is anything other than `A` or `B`.
